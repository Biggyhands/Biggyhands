## 👨‍💻 About Me

I'm a **Software Engineering graduate** with a previous background in **Microbiology**, currently focused on building solid foundations in software development and turning complex problems into practical solutions.

My journey into software wasn't linear.

I started my professional life in microbiology, discovered that I wanted a different challenge, and eventually decided to rebuild my career around technology. Since then, I've been deliberately developing my skills through **programming, projects, continuous learning, and disciplined practice**.

I don't try to learn everything at once.

I prefer to understand **how things work, why they work, and how to build them well**.

> *"I believe consistency compounds."*

## 📚 Learning Philosophy

I learn best when I can connect **concept → implementation → feedback**.

Instead of simply memorizing syntax, I try to understand the underlying model and then reinforce it by building.

```text
Understand
    ↓
Experiment
    ↓
Build
    ↓
Break
    ↓
Debug
    ↓
Improve
    ↓
Repeat
```
